8. Scope cuts, in this order, decided at each gate

  1. Third prompt strategy beyond decomposition and CoT, and self-consistency (note as a limitation; the brief asks for at least 3 strategies, so keep structured + few-shot, CoT and decomposition if at all possible).
  2. LLM-as-judge. Keep the rule-based scorer plus a small human-checked sample.
  3. Phoenix container: use the JSONL trace page instead.
  4. Cross-session memory beyond one session store.
  5. Corpus growth beyond what is cleanly collected. Report the real number.
  6. Reranker, only as a last resort. The brief names it, so report honestly if it is dropped.
Do not cut: frozen eval and baseline numbers; hybrid retrieval with recall@k reported separately from answer quality; planner/executor/critic with the 10-step cap; at least 3 real tools; one real trace view; Docker run from a clean clone; injection test results; human-in-the-loop for leave actions; the "what we did to compensate for a small model" section (explicitly graded).
